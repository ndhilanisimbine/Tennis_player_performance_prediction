# 🎾 ATP Tennis Player Performance Prediction

## 📌 Project Overview
This project analyzes **ATP (Association of Tennis Professionals) player performance** using **linear regression models** to predict player **Winnings** based on various tennis statistics.

The dataset contains match statistics for the **top 1500 ATP players (2009-2017)**, including **Aces, First Serve %, Break Points Saved, Service Games Won, and more**.

## 🚀 Features
✔ **Exploratory Data Analysis (EDA)**
   - Visualizes key relationships using scatter plots, histograms, and heatmaps.
   - Identifies features that impact winnings.
   
✔ **Linear Regression Models**
   - **Single Feature Model:** Uses one feature to predict Winnings.
   - **Two-Feature Model:** Uses two features to predict Winnings.
   - **Multiple Feature Model:** Uses several statistics to improve predictions.
   - **Model Evaluation:** Measures accuracy using **Mean Squared Error (MSE)** and **R² Score**.

✔ **Google Colab & GitHub Integration**
   - Easily run this project in Google Colab.
   - Data stored in `tennis_stats.csv` (upload required).

## 📂 Dataset
- The dataset is stored in **`tennis_stats.csv`**.
- It includes **23 columns** with statistics on player performance.
- No missing values in the dataset.
